# Endpoints de API validados

## Wikipedia (Action API)
- Base: `https://en.wikipedia.org/w/api.php`
- Búsqueda: `?action=query&list=search&srsearch=<término>&format=json&srlimit=5`
- User-Agent requerido: `ProyectoHistorico/1.0 (email)`

## Wikidata
- Base: `https://www.wikidata.org/w/api.php`
- Búsqueda de entidad: `?action=wbsearchentities&search=<término>&language=en&format=json&limit=5`

## Qiuwen Baike (MediaWiki)
- Base: `https://www.qiuwenbaike.cn/api.php`
- Búsqueda: `?action=query&list=search&srsearch=<término_en_chino>&format=json&srlimit=5`
